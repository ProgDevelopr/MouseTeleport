<h1 align="center">
    MouseTeleport (MsTp)
</h1>
<h4>A script inspired by Bog's video where he struggles to make a mouse teleporter program:
<a href="https://www.youtube.com/watch?v=vlXdUU5pd_0&t=54s"> Click here to watch it.</a>
</h4>

<h4>
Press ESC+Shift (left) to save the mouse position.

Press ESC+ALT (left) to move the mouse to it's saved position.

Please make sure to run `pip install -r requirements.txt` to install all dependencies.


Thanks to <a href="https://www.youtube.com/@bogxd">Bog</a> for the idea.
</h4>
